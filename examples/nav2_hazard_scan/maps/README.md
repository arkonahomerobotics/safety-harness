# `warehouse.yaml` / `warehouse.pgm`

Pulled unmodified from the [`navigation2`](https://github.com/ros-navigation/navigation2) project's
own example maps, `nav2_bringup/maps/warehouse.{yaml,pgm}` (fetched 2026-09-28 from the `main`
branch). This is a real, standard-format Nav2 map — a 1006x1674-cell occupancy grid at 0.03 m/cell
(~30 m x 50 m), used here because it's real navigation2-project data rather than a synthesized
stand-in. `navigation2`'s repository license is mixed LGPL-2.1-or-later / Apache-2.0 by file — see
its own `LICENSE`; this map data is redistributed here for the same non-commercial, illustrative,
open-source-example purpose it already serves in that project.
